組み込みのプリセットは、実機で回せたときの設定です。出どころと測定結果は docs/motor-settings.md にあります。 ESC 設定タブで「今の値をプリセットに保存」すると、このブラウザに保存されます。

⚠ プロペラを外すか、モーターを固定してから使ってください。Esc キー / スペースキーでいつでも全停止します。 タブを移る・ページを隠す・接続が切れると止まります。

HEX ファイルはローカルから選びます: Bluejay · AM32。 レイアウト (例 #A_H_30#) と MCU が ESC と一致しないものは、強制しない限り書き込みません。

使い方

  1. PC の Chrome か Edge で開きます (Web Serial を使います)。
  2. pico-esc-tool の Pico、または Betaflight のフライトコントローラーを USB でつなぎ、「接続」を押してポートを選びます。ESC の電源も入れておきます。
  3. 「ESC を読み込む」で、各 ESC がブートローダーに入り設定を読みます (1 個あたり数秒)。
  4. 値を変えるかプリセットを反映し、「書き込む」を押します。書いたあと読み戻して照合します。
  5. モーターテストに移るとパススルーを抜けます (ESC が再起動します)。

対応

  • BLHeli_S 16.x、Bluejay (0.9〜0.22 系)、BlueGill、AM32 (eeprom 版 2 以上)。BLHeli_32 と Atmel は非対応。
  • ファーム書き込みは SiLabs の 512 バイトページ品 (EFM8BB1/BB2 など) と AM32。
